# Mushroom classification

The model was trained using the Mushroom Classification dataset from Kaggle, which contains categorical features such as cap shape, cap color, odor, gill size, stalk characteristics and habitat.

The categorical values were converted into numerical labels using LabelEncoder before training a DecisionTreeClassifier. The dataset was then split into training and testing sets, allowing the model's performance to be evaluated on unseen data.

The project includes:

Data loading and preprocessing
Label encoding of categorical features
Train/test split
Decision Tree model training
Model evaluation using accuracy, confusion matrix, and classification report
Feature importance analysis to identify the most influential mushroom characteristics

Technologies Used

Python
Pandas
Scikit-learn

Dataset

Kaggle Mushroom Classification Dataset

This is a complete supervised machine learning workflow, from data preprocessing to model evaluation, using a simple and interpretable classification algorithm.
